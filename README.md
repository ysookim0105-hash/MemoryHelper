# 기억력 게임 보조 (MemoryHelper)

세븐나이츠리버스 기억력 미니게임에서 화면을 자동 캡처해 카드 위치를 기억해주는 Android 앱.

## 작동 방식

1. 앱에서 카드 격자 영역(슬라이더)과 열/행 수를 설정
2. [시작] → 화면 캡처 권한 허용
3. 게임으로 이동 → 화면 위에 버튼 바 표시
4. [● REC] 탭 → 카드 감지 시작
5. 게임이 카드를 공개할 때마다 자동으로 pHash를 계산해 같은 카드끼리 같은 번호 부여
6. [보기] 탭 → 반투명 그리드 오버레이로 결과 확인

## GitHub Actions로 APK 빌드하기

1. 이 저장소를 GitHub에 push
2. Actions 탭 → "Build APK" 워크플로우 실행 (자동 또는 수동)
3. 완료 후 Artifacts에서 `MemoryHelper-debug.apk` 다운로드
4. 폰에서 설치 (설정 → 알 수 없는 앱 허용 필요)

## 필요 권한

| 권한 | 용도 |
|---|---|
| 다른 앱 위에 표시 | 버튼 바 + 그리드 오버레이 |
| 화면 캡처 | 카드 이미지 분석 |
| 포그라운드 서비스 | 백그라운드 실행 유지 |
| 알림 | 포그라운드 서비스 알림 |

## 감도 조정

- 카드가 잘 안 잡힌다 → 감도 슬라이더를 낮춤 (더 민감)
- 엉뚱한 칸이 잡힌다 → 감도 슬라이더를 높임 (덜 민감)
- 기본값(슬라이더 중앙)으로 시작 권장

## 주의

- 화면 캡처 권한 창에서 **전체 화면** 선택
- 버튼 바는 카드 격자 바깥에 위치시키기
- 게임 약관에 따라 외부 프로그램 사용이 제한될 수 있음
